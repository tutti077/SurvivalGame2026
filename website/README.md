# Two Track Games — website

Static site, no build step. Upload the **contents of this folder** to any static host
(Netlify drop, GitHub Pages, Cloudflare Pages, itch, plain FTP) — `index.html` is the home page.

| Page | File |
|------|------|
| Home (trailer, studio intro, secret-project teaser with sideways redacted files) | `index.html` |
| Company | `company.html` |
| Contact | `contact.html` |

## Things to edit

- **Email + social links:** `js/site-config.js` (twotrackgames@gmail.com, Instagram, X). An empty social link is hidden everywhere.
  The contact form opens the visitor's mail app pre-filled to that email (no server needed).
- **Logos:** clean vector rebuilds of the banner and the round badge live in `assets/brand/`
  (SVG + PNG: banner 1500 / 3000 px, transparent banner, badge 400 / 1024 px). They are generated by
  `Tools/brand/make_brand_logos.py` at the project root, the one place the logo geometry lives;
  re-run it after changing a shape, then paste its printed paths into the `#tt-banner` symbol
  in `index.html` (the trailer reads those paths). `assets/logo-square.svg` is the badge used in
  the nav, footer, page wipe and favicon.
- **Profile picture:** save it as `assets/brand/profile.png` — it appears on the Company page
  (greyscale with a red tint) once you uncomment its block in `company.html`.
- **Secret project teaser:** the *Something’s coming* section and the redacted file cards in `index.html` — swap in the real announcement when it’s time.

## How it works

- `js/intro.js` — the ~3 s trailer (once per browser session, skip with the button / Esc):
  a sideways red train switches from the top track to the bottom one and brakes into the logo.
  Footer *Replay intro* plays it again.
- `js/scene.js` — the hero backdrop: a slow flyover of generated terrain ridge lines in red haze; the camera rises as you scroll.
- `js/main.js` — any section with `data-pin` sticks while it scrolls and gets a CSS variable
  `--p` from 0 to 1; the CSS in `css/style.css` turns that into the split title, fold-open
  panels, sideways gallery and scattering headings.
- Visitors with *reduce motion* switched on get no trailer and no scroll effects.
- Colours are limited to black, red, white and greys (`:root` tokens at the top of the CSS).
