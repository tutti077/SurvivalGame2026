Heres how it should work, math wise.

Inputs:
D = incoming physical damage
A = total armor from all equipped pieces

If D <= 0:
    finalDamage = 0

Else if A <= 0:
    finalDamage = D

Else if A < D / 2:
    finalDamage = D - A

Else:
    finalDamage = (D * D) / (4 * A)



100 damage, 20 armor:
20 < 100 / 2
Final = 100 - 20
Final = 80 damage

100 damage, 50 armor:
50 >= 100 / 2
Final = 100² / (4 × 50)
Final = 10,000 / 200
Final = 50 damage

100 damage, 100 armor:
Final = 100² / (4 × 100)
Final = 25 damage

20 damage, 50 armor:
Final = 20² / (4 × 50)
Final = 2 damage
